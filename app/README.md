# Подходы

Журнал тренировок: упражнения, подходы и недельный объём по мышцам со схемой тела.
Работает без интернета, ставится на телефон как приложение. Данные хранятся на устройстве.

## Как выложить на GitHub Pages

1. На github.com нажми **New repository**, назови, например, `podhody`, выбери **Public**, создай.
2. В репозитории: **Add file → Upload files**, перетащи всё содержимое этой папки
   (`index.html`, `manifest.webmanifest`, `sw.js`, `README.md` и папку `icons`), нажми **Commit changes**.
3. **Settings → Pages**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)`, **Save**.
4. Через 1–2 минуты сайт будет по адресу `https://<твой-ник>.github.io/podhody/`.

## Установка на телефон

- **iPhone:** открой адрес в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** открой в Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

## Данные

- Записи хранятся в памяти браузера на том устройстве, где ты их вносишь.
- Журнал → **Бэкап → Скачать бэкап** сохраняет всё в `.json`. **Загрузить из файла** добавляет записи из бэкапа
  (так же переносятся данные из версии в Claude и между устройствами).
- Делай бэкап время от времени: если удалить приложение или очистить данные сайта, записи пропадут.

## Обновление

Замени файлы в репозитории новыми (Upload files поверх старых). Приложение подтянет новую версию
при следующем открытии с интернетом; записи не трогаются.
